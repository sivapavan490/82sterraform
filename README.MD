# Installation steps for  terraform
1.download the required zip file of terraform on below link. Later after downloading the file extract that zip file.

```
https://developer.hashicorp.com/terraform/install#windows
```
2. To acess the terraform set the path in environmental variables.

copy the path of extract file on pc. And paste the path of environmental variables

3. To connect terraform with aws we should install aws cli on below link according to our requirement

```
https://docs.aws.amazon.com/cli/latest/userguide/getting-started-install.html
```
Above one url will provide the place of downlading aws cli according to our requirment
            
            (OR)

4.Download and run the AWS CLI MSI installer for Windows (64-bit):
```
https://awscli.amazonaws.com/AWSCLIV2.msi
```
